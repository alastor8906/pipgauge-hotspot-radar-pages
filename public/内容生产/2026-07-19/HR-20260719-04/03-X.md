# X 帖串

## 1/5

Two different tickers can still create one portfolio risk when they share the same earnings window.

Sizing each trade separately may hide the combined gap exposure.

## 2/5

Example: $10,000 account.

$2,000 TSLA position
$2,000 GOOGL position

$4,000 is exposed to the same event window.

## 3/5

If both positions gap against the account:

5% each → about -$200 combined
10% each → about -$400
15% each → about -$600

This is a stress test, not a forecast.

## 4/5

A chart stop does not guarantee the fill price after an earnings gap.

Planned stop heat and gap risk are different scenarios. Measure both.

## 5/5

Reverse the math:

Maximum combined loss: $200
Stress gap: 10%

Maximum combined position value ≈ $2,000.

Different tickers do not automatically mean diversified event risk.
