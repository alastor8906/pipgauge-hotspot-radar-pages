# X thread draft

1/ Two stock positions can turn into one risk event when both companies report after the close on the same day.

The useful question is not “which one will beat?” It is: what happens to the account if both positions gap against it?

2/ Example: $10k account, with $2,500 notional in each of two stocks.

Combined loss if both move against the account:

- 5% gaps: $250
- 10% gaps: $500
- 15% gaps: $750

These are scenarios, not forecasts.

3/ A normal stop does not guarantee the exit price through an after-hours gap. Planned stop risk and gap risk need separate calculations.

4/ Count dollars, not tickers. Two symbols do not create diversification if the same catalyst and market narrative can move both at once.

5/ Better sequence:

- Set one dollar-risk budget for the event cluster
- Allocate it across the positions
- Calculate each size
- Stress-test a larger simultaneous gap

6/ Notional exposure is not portfolio heat. The same $5k of holdings can produce very different modeled losses depending on the gap assumption.

7/ A portfolio tool can organize the numbers after the scenario is defined. It cannot predict the report. The goal is a visible account consequence, not a confident headline call.

Educational example only. Not financial advice.
