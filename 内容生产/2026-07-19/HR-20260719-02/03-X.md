# X 帖串

## 1/5

“Nasdaq fell 4%” is a market headline, not an account-risk number.

For a NAS100 CFD position, you still need the index level, broker point value and lot size.

## 2/5

At an illustrative 25,000 index level:

25,000 × 4% = 1,000 index points.

That still does not tell you the dollar P&L.

## 3/5

Assume, only as an example, that 1.00 lot equals $1 per point.

A 250-point adverse move:

0.10 lot → -$25  
0.50 lot → -$125  
1.00 lot → -$250

## 4/5

For a $10,000 account with a $100 risk budget:

$100 ÷ (250 points × $1/point) = 0.40 lot.

If your broker uses another point value, every result changes.

## 5/5

The correct order is:

percentage → index points → broker point value → lot size → account P&L.

Margin is a separate calculation. Available leverage does not define acceptable risk.
