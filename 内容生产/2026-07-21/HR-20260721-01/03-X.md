# X 帖串

## 1/5

On July 21, USD/JPY was around 162.53. A 100–300 pip reversal sounded dramatic, but the account impact still depended on position size.

At that historical level in a USD account, 1 standard lot was worth about $6.15 per pip.

## 2/5

For 100 / 200 / 300 pips, the approximate dollar changes are:

0.1 lot → $62 / $123 / $185  
0.5 lot → $308 / $615 / $923  
1.0 lot → $615 / $1,231 / $1,846

Same chart move. Very different account risk.

## 3/5

Now assume a $10,000 account and a fixed $100 loss budget.

100-pip stop → ~0.16 lot  
200-pip stop → ~0.08 lot  
300-pip stop → ~0.05 lot

Wider stop, smaller size.

## 4/5

That matters more around intervention talk because the problem is not only direction.

Fast reversals can also mean wider spreads and slippage. The clean stop calculation is a baseline, not a guaranteed fill.

## 5/5

The useful question is not “Will Japan intervene?”

It is: “If this position is wrong by 100 pips, what happens to the account?”
