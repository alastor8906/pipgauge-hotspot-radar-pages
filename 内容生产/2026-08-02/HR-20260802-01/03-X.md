# X thread draft

1/ The U.S.–Japan yen intervention story is unusual. The account-risk math is not.

Using USD/JPY 157.40 as a historical reference, 1 standard lot is about $6.35 per pip for a USD account. No direction forecast—just exposure math.

2/ A 100 / 200 / 300-pip move is roughly:

0.10 lot → $64 / $127 / $191

0.50 lot → $318 / $635 / $953

1.00 lot → $635 / $1,271 / $1,906

3/ For a $10,000 account with a fixed $100 loss budget, the theoretical size is about:

100 pips → 0.15 lot

200 pips → 0.07 lot

300 pips → 0.05 lot

Rounded down for ordinary lot steps.

4/ The clean table is only a baseline. Intervention-style moves can widen spreads, add slippage and skip intended prices. A stop does not guarantee the exact fill.

5/ The durable rule: when the adverse distance gets larger, the lot size must get smaller to preserve the same dollar risk.

Check the broker's contract size, pip value and lot step before using any example. Educational only; not a USD/JPY forecast.
